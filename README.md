# ExactUpscale

**Get exactly the size you need. No cropping, no stretching, no invented details.**

ExactUpscale is a fast, private image upscaler for macOS, Windows, and Linux. Choose an
exact target size and get a faithful enlargement that keeps the original shape. Everything
runs on your device, so your photos never leave your computer.

**ExactUpscale is an [Aurora Ivy](https://aurora-ivy.tech) product.**

## What it does

- **Exact target sizes**: enter the pixel dimensions you need (for example 3840 × 2160) and
  get exactly that.
- **Faithful**: no cropping, stretching, sharpening, or invented detail. We change nothing
  else.
- **Private and offline**: processing happens entirely on your device. No uploads, no
  account, no internet required.
- **Batch processing**: upscale a single image or a whole set (Pro).
- **WebP output**: small, high-quality files.

## Free vs Pro

The free version handles single images up to 2K with the Fast model, for personal use.
[Pro](https://exactupscale.app) unlocks batch processing, any resolution, the Max model, and
a commercial license.
